    Portable settings

    localStorage only affects this browser. Export the JSON, paste it into DEFAULT_CONFIG, or store it in a backend to publish for everyone.

    Backup / restore

    JSON

    To make changes permanent without a backend: export the JSON, paste the object into DEFAULT_CONFIG inside index.html, then redeploy.

    Admin password

    SHA-256

    Only a SHA-256 hash is stored in CONFIG, never the password itself. This is still a client-side gate, not server security.

    Cloud adapter

    Optional

    For changes visible to all visitors, connect a backend. Add your project keys in the REMOTE_ADAPTER block near the bottom of this file, then implement loadRemote() and saveRemote().

    const REMOTE_ADAPTER = { provider: "none", // "supabase" | "firebase" supabase: { url: "https://YOUR-PROJECT.supabase.co", anonKey: "YOUR-ANON-KEY", table: "portfolio_config", rowId: "main" }, firebase: { apiKey: "YOUR-API-KEY", projectId: "YOUR-PROJECT-ID", collection: "portfolio", docId: "main" } };

    Keep public write access locked down with RLS or server functions. Never put a service-role or admin key in this file.
